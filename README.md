Bank Management System in C

A simple console-based Bank Management System developed using the C programming language and Linked Lists.

Features

- Create new bank accounts
- Deposit money
- Withdraw money
- Check account balance
- Display all registered accounts
- Prevent duplicate account numbers
- Dynamic memory allocation using "malloc()"
- Memory cleanup using "free()"

Technologies Used

- C Programming
- Structures
- Linked Lists
- Dynamic Memory Allocation

How to Run

Compile the program:

gcc main.c -o bank

Run the program:

./bank

Project Purpose

This project demonstrates the use of structures, linked lists, pointers, functions, and dynamic memory allocation in C.
