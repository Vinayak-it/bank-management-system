🏦 Bank Management System

A console-based Bank Management System developed in C using Linked Lists and Dynamic Memory Allocation.

📌 Overview

This project provides a simple banking interface that allows users to create accounts, deposit and withdraw money, check balances, and view registered accounts.

It demonstrates fundamental concepts of C programming, including structures, pointers, linked lists, functions, and dynamic memory management.

✨ Features

- Create new bank accounts
- Prevent duplicate account numbers
- Deposit money into accounts
- Withdraw money with balance validation
- Check individual account balances
- Display all registered accounts
- Dynamic memory allocation using "malloc()"
- Memory deallocation using "free()"

🛠️ Technologies Used

- C Programming Language
- Structures
- Linked Lists
- Pointers
- Dynamic Memory Allocation

Compile

gcc main.c -o bank

Run on Linux/macOS

./bank

Run on Windows

bank.exe

- Dynamic memory allocation
- Input/output operations

⚠️ Limitations

- Account information is stored in memory and is lost when the program exits.
- This project is educational and is not intended for real financial transactions.
